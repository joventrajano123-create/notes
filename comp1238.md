## Week 1 - History

- Writing systems were developed to record and communicate information.
- Different methods have been used throughout history to store and share information.
- Cuneiform means "wedge shaped" and was written by pressing a stylus into clay.
- The Sumerians used a base-60 positional number system for numbers above 60.

## Week 2 - Bits and Bytes

- Computers use different methods to store and represent information.
- Computer memory and storage are used to hold data.
- A byte is made up of 8 bits.
- ASCII is a standard used to represent characters in computers.

## Week 3 - Text Structure

- Text can be organized in different ways to make information easier to read and understand.
- Markup languages provide instructions for displaying and interpreting text.
- Markdown is a simple markup language designed to be readable as plain text.
- JSON and XML are text-based formats used to store structured data.

## Week 4 - Working With Text

- Keyboards and text editors are important everyday tools for working with computers.
- Searching tools make it easier to find specific text and patterns.
- Touch typing means typing without looking at the keyboard and using all fingers.
- Regular expressions (RegEx) are used to create search patterns for finding text.

## Week 5 - Command Line Interfaces

- The Command Line Interface (CLI) lets users interact with a computer by typing commands.
- CLI is useful for precise control, automation, remote work, and tasks that may not have a GUI.
- Common CLI commands include `ls`, `pwd`, `cd`, `cat`, `cp`, `mv`, and `mkdir`.
- SSH (Secure Shell) lets you securely connect to and control another computer remotely.
